📚 Book Manager - менеджер личной библиотеки

Одностраничное веб-приложение для учёта личных книг: добавление, редактирование,
удаление, фильтрация по статусу и жанру, поиск и сортировка. Написано на чистом
JavaScript с использованием нативных DOM API - без фреймворков и библиотек.

🚧 Проект в разработке. Скоро здесь появятся скриншоты и ссылка на демо.

Планируемый функционал

- ➕ Добавление книги - название, автор, жанр, статус, оценка 1-5
- ✏️ Редактирование существующей записи
- 🗑️ Удаление с подтверждением в модальном окне
- 🔍 Поиск по названию и автору
- 🎯 Фильтрация по статусу («читаю / прочитано / хочу прочитать») и жанру
- ↕️ Сортировка по названию, автору или оценке
- 📊 Статистика - всего книг, читается, прочитано
- 💾 Автосохранение в `localStorage` - данные не теряются при перезагрузке


Технологии

- HTML5 - семантическая разметка
- CSS3 -  Grid, Flexbox, CSS-переменные
- JavaScript (ES2022) - ES-модули, нативные DOM API
- localStorage - хранение данных на клиенте
